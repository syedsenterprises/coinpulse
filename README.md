# CoinPulse — Crypto, Clearly

Live demo site: a crypto landing page with a working virtual trading wallet.

**What actually works (in your browser, no server needed):**
- Simulated price ticker that moves every few seconds
- USD ↔ BTC/ETH/SOL converter at demo prices
- Virtual $10,000 wallet: buy/sell, holdings, portfolio value, trade log —
  all saved in localStorage, with a reset button

**Honest limits:** prices are simulated random walks, not live market data.
No real money, no real trading, no account. This is not financial advice.
Connect a price API and a real exchange backend to trade for real.
